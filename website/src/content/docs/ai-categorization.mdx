You pick one during the setup wizard, and you can switch any time from *Settings → AI*. Previously-categorized transactions stay categorized; only new transactions go through the new provider.

## Claude

Spent uses **Claude Haiku 5.5** by default, with reasoning turned off. Categorizing a batch is a short classification task, so reasoning would only add cost and wait time. Claude Haiku 4.5 is also available in the model picker.

**Setup:**

1. Go to `console.anthropic.com` and create an API key under *Settings → API Keys*.
2. Paste it into Spent's setup wizard (or *Settings → AI*).
3. Done. Your key is encrypted at rest with the same AES-256-GCM that protects your bank credentials.

<Callout variant="note">
Spent sends Anthropic's API the **merchant name and amount** of each new transaction — no personal IDs, no bank credentials. Anthropic's commercial API does not train on submitted data.
</Callout>

## OpenAI

Spent uses **GPT-6 Luna** by default, with reasoning turned off (`reasoning.effort: "none"`) for the same reason as Claude. Requests are sent with `store: false`, so OpenAI does not keep the responses for later retrieval.

**Setup:**

1. Go to `platform.openai.com/api-keys` and create an API key.
2. Paste it into Spent's setup wizard (or *Settings → AI*) and choose OpenAI.
3. Done. Your key is encrypted at rest with AES-256-GCM, like the Claude key.

<Callout variant="note">
Spent sends OpenAI's API the **merchant name and amount** of each new transaction, and nothing else: no personal IDs, no bank credentials.
</Callout>

## Ollama

Runs a language model on your own machine. Slower than the cloud providers, but every byte stays local.

**Setup:**

1. Install Ollama from **[ollama.com/download](https://ollama.com/download)**.
2. In a terminal:
   ```sh
   ollama pull qwen3.5:9b
   ```
   (6.6 GB download.) Or skip this step: Spent's setup wizard can download the model for you.
3. In Spent's setup wizard, choose Ollama and pick the model.

Spent talks to Ollama at `http://localhost:11434`, its default.

<Callout variant="gotcha">
`qwen3.5:9b` needs about **8 GB of free RAM or VRAM** while running. In our tests on synthetic transactions it was clearly more accurate than the Llama models, Hebrew merchant names included. On a machine with less memory, pick `llama3.2:3b` and expect more corrections.
</Callout>

## Manual

Skip AI entirely. Each transaction starts in *Uncategorized*. You assign categories by clicking the category badge in the dashboard.

Slow, but perfect privacy and perfect accuracy.

## How batching works

When Spent syncs, it groups uncategorized transactions into batches of **50** and sends each batch to the chosen provider in one round-trip. This keeps cost and latency low.

<ForDevelopers summary="What the prompt and retry logic look like">

The prompt (defined in `src/server/ai/prompts.ts`) is shared between Claude, OpenAI and Ollama. It asks the model to return JSON: an array of objects with `merchant`, `category`, and a confidence score.

Spent retries up to **three times** on malformed output. Persistent failures fall back to *Uncategorized* — never to a wrong category.

Default models: `claude-haiku-5-5` for Claude, `gpt-6-luna` for OpenAI and `qwen3.5:9b` for Ollama. The cloud model lists live in `src/lib/ai-models.ts` and the Ollama list in `src/lib/ollama-model-options.ts`.

</ForDevelopers>

## Switching providers

Switch any time from *Settings → AI*. Previously-categorized transactions stay categorized; only new transactions (and ones you've explicitly re-categorized) go through the new provider.

<Callout variant="gotcha">
**If you switch away from Claude or OpenAI, revoke your API key** in the Anthropic console or on the OpenAI platform. Spent will discard it locally, but rotating it is the safe move.
</Callout>
